# First Aid VR

โครงงาน MMI320 สำหรับฝึกสังเกตบาดแผล เลือกอุปกรณ์ และทำตามลำดับการปฐมพยาบาลในห้องจำลอง ออกแบบให้ฝึกแบบนั่งได้ มีคำแนะนำและเหตุผลเมื่อเลือกผิด ไม่มีคะแนนหรือเวลาจำกัดการฝึก

## เปิดโปรเจกต์

1. เพิ่มโฟลเดอร์นี้ใน Unity Hub แล้วเปิดด้วย **Unity 6000.5.9f1**
2. รอ Unity โหลดแพ็กเกจ จากนั้นเปิด `Assets/Scenes/FirstAid.unity`
3. กด **Play** และคลิกหน้าต่าง Game หากไม่มีแว่นจะเริ่มด้วยโหมดเมาส์ กด **F2** เพื่อสลับไปทดลอง XR Simulator ใน Editor

ใช้ XR Interaction Toolkit 3.5.1, Input System และ OpenXR ตามไฟล์ `Packages/manifest.json`

## วิธีฝึก

- หยิบคลิปบอร์ดบนเคาน์เตอร์ซ้ายเพื่อเลือกเคสและอ่านเช็กลิสต์ มี 3 เคส ได้แก่ แผลถลอก แผลมีดบาดตื้น และแผลน้ำร้อนลวก เคสละ 2 จุด
- กด **ไทย** หรือ **EN** บนกระดาษเพื่อเปลี่ยนภาษา ชื่ออุปกรณ์จะแสดงเหนือของเฉพาะตอนชี้ และใช้ภาษาเดียวกับเช็กลิสต์
- เปิดก๊อก ล้างมือทั้งสองข้าง และหยิบถุงมือจากกล่องทีละข้างก่อนเริ่มรักษา เมื่อเปลี่ยนผู้ป่วยให้เตรียมมือใหม่
- ตรวจแผลก่อนหยิบอุปกรณ์ เมื่อใช้อุปกรณ์ถูกขั้นตอนจะมีข้อความขึ้นตรงแผล เมื่อใช้ผิด เกมจะแสดงคำแนะนำสีแดงตรงแผลในโหมดเมาส์ หรือใกล้มือที่ถืออุปกรณ์ในโหมด XR
- เคสที่ต้องล้างแผลให้เอียงขวดน้ำหรือน้ำเกลือเหนือแผล ความคืบหน้าจะเพิ่มขณะที่สายน้ำโดนจุดแผล
- ขวดน้ำและขวดน้ำเกลือมีปริมาณจำกัด ดูเปอร์เซ็นต์ตอนชี้ที่ขวด เติมขวดน้ำโดยถือปากขวดตั้งตรงใต้ก๊อก ส่วนขวดน้ำเกลือที่หมดจะเปลี่ยนเป็นขวดใหม่เมื่อคืนที่เดิม
- เคสน้ำร้อนลวกใช้ก๊อกน้ำที่อ่าง เวลาเย็นแผลในเกมย่อมาจากการใช้น้ำไหล 20 นาที

## การควบคุม

| โหมดเมาส์ | การทำงาน |
|---|---|
| คลิกคลิปบอร์ด หรือ **Tab** | หยิบคลิปบอร์ดมาอ่าน |
| ปุ่มในคลิปบอร์ด หรือ **1 / 2 / 3** | เลือกเคส |
| **B** | เปลี่ยนตำแหน่งฝึก |
| **I** หรือคลิกจุดแผล/ปุ่มตรวจแผล | ตรวจแผล |
| คลิกแล้วเลื่อนเมาส์ไปที่เครื่องหมาย | หยิบอุปกรณ์และนำไปใช้ |
| กด **Shift** ค้างขณะถือขวด | เอียงขวดเพื่อเท |
| คลิกคันโยกที่อ่าง | เปิดหรือปิดก๊อก |
| กดคลิกซ้ายค้างใต้สายน้ำ แล้วคลิกกล่องถุงมือ 2 ครั้ง | ล้างมือและใส่ถุงมือทีละข้าง |
| ถือขวดน้ำแล้วชี้ใต้ก๊อกโดยปล่อย **Shift** | ตั้งขวดเพื่อเติมน้ำ |
| คลิกขวา | วางคลิปบอร์ดหรือคืนอุปกรณ์ |
| **L** หรือ **F3** | สลับไทย–อังกฤษ |
| **R** | เริ่มตำแหน่งปัจจุบันใหม่ |
| **F2** | สลับเมาส์กับ XR Simulator ใน Editor |

**คอนโทรลเลอร์ XR** ใช้ Grip หยิบคลิปบอร์ดหรืออุปกรณ์จากระยะไกล ของจะเข้ามาติดมือและนิ้วจะกำตามรูปอุปกรณ์ ใช้มืออีกข้างชี้แล้วกด Trigger เพื่อเลือกปุ่มบนกระดาษ เอียงมือที่กำขวดเพื่อเท แล้วปล่อย Grip เพื่อคืนของ

ที่อ่างให้ชี้คันโยกแล้วกด Grip เพื่อเปิดก๊อก จากนั้นยื่นมือเปล่าทีละข้างใต้สายน้ำ เมื่อข้อความยืนยันขึ้นแล้ว ใช้มือข้างที่ล้างแล้วกด Grip ที่กล่องถุงมือเพื่อใส่ถุงมือข้างนั้น ถือขวดน้ำตั้งตรงให้ปากขวดอยู่ใต้ก๊อกเมื่อต้องการเติมน้ำ

**XR Simulator** ใช้ WASD เคลื่อนที่, เมาส์ขวาหมุนมุมมอง, G แทน Grip, T แทน Trigger, Tab สลับโหมด และ [ หรือ ] เลือกมือซ้ายหรือขวา ปุ่มลูกศรใช้หมุนมือที่กำลังควบคุม คลิกซ้ายที่ปุ่มบนคลิปบอร์ดเพื่อเลือก หรือกด F3 เพื่อสลับภาษา


สถานะและขอบเขต

ใช้งานและตรวจการทำงานผ่าน Unity Editor / Play Mode ยังไม่ได้ทดสอบกับแว่น VR จริง และไม่ได้สร้าง Build ในงานรอบนี้ ความคืบหน้าเก็บเฉพาะรอบการเล่นปัจจุบัน โปรแกรมย่อขั้นตอนเพื่อการเรียนรู้ ไม่ใช่การประเมินทักษะหรือคำแนะนำสำหรับรักษาผู้บาดเจ็บจริง
