# First Aid VR

โครงงาน MMI320 สำหรับฝึกสังเกตบาดแผล เลือกอุปกรณ์ และทำตามลำดับการปฐมพยาบาลในห้องจำลอง ออกแบบให้ฝึกแบบนั่งได้ มีคำแนะนำและเหตุผลเมื่อเลือกผิด ไม่มีคะแนนหรือเวลาจำกัดการฝึก

## เปิดโปรเจกต์

1. เพิ่มโฟลเดอร์นี้ใน Unity Hub แล้วเปิดด้วย **Unity 6000.5.9f1**
2. รอ Unity โหลดแพ็กเกจ จากนั้นเปิด `Assets/Scenes/FirstAid.unity`
3. กด **Play** และคลิกหน้าต่าง Game หากไม่มีแว่นจะเริ่มด้วยโหมดเมาส์ กด **F2** เพื่อสลับไปทดลอง XR Simulator ใน Editor

ใช้ XR Interaction Toolkit 3.5.1, Input System และ OpenXR ตามไฟล์ `Packages/manifest.json`

## วิธีฝึก

- เลือกฝึกได้ 3 เคส ได้แก่ แผลถลอก แผลมีดบาดตื้น และแผลน้ำร้อนลวก แต่ละเคสมีตำแหน่งฝึก 2 จุด
- ตรวจดูตำแหน่งและคำอธิบายแผลก่อนเริ่ม แล้วหยิบอุปกรณ์ไปค้างไว้ใกล้จุดที่ทำเครื่องหมาย
- ระบบยอมรับขั้นตอนที่ถูกต้องและให้เหตุผลเมื่อเลือกผิด เมื่อทำครบจะเห็นวัสดุปิดแผลและสถานะสำเร็จ
- เคสน้ำร้อนลวกใช้จุดเปิดน้ำที่อ่างล้างมือ ก่อนคลุมแผลด้วยฟิล์มหลวม ๆ เวลาเย็นแผลในโปรแกรมเป็น **เวลาจำลองของการใช้น้ำไหล 20 นาที**

## การควบคุม

| โหมดเมาส์ | การทำงาน |
|---|---|
| คลิกเมนู หรือ `1` / `2` / `3` | เลือกเคส |
| `B` | เปลี่ยนตำแหน่งฝึก |
| `I` หรือคลิกจุดแผล/ปุ่มตรวจแผล | ตรวจแผลและอ่านคำอธิบาย |
| คลิกอุปกรณ์ แล้วเลื่อนเมาส์ไปค้างที่เครื่องหมาย | หยิบและใช้อุปกรณ์ |
| คลิกขวา | คืนอุปกรณ์ |
| `R` | เริ่มเคสปัจจุบันใหม่ |
| `F2` | สลับเมาส์กับ XR Simulator เฉพาะใน Editor |

**คอนโทรลเลอร์ XR:** ใช้ Grip หยิบอุปกรณ์และค้างไว้ใกล้แผล ใช้ Grip ที่ก๊อกน้ำ และชี้แล้วกด Trigger เพื่อเลือกเมนู ปล่อย Grip เพื่อคืนอุปกรณ์

**XR Simulator:** `WASD` เคลื่อนที่, เมาส์ขวาหมุนมุมมอง, เมาส์ซ้ายชี้และเลือก, `G` = Grip, `T` = Trigger, `Tab` สลับโหมดการควบคุม, `[` / `]` เลือกอุปกรณ์ซ้าย/ขวา กดวงเล็บเดิมสองครั้งเพื่อสลับคอนโทรลเลอร์กับมือจำลอง

## สถานะและขอบเขต

ใช้งานและตรวจการทำงานผ่าน Unity Editor / Play Mode ยังไม่ได้ทดสอบกับแว่น VR จริง และไม่ได้สร้าง Build ในงานรอบนี้ ความคืบหน้าเก็บเฉพาะรอบการเล่นปัจจุบัน โปรแกรมย่อขั้นตอนเพื่อการเรียนรู้ ไม่ใช่การประเมินทักษะหรือคำแนะนำสำหรับรักษาผู้บาดเจ็บจริง

## แหล่งอ้างอิงและเครดิต

- [NHS: Cuts and grazes](https://www.nhs.uk/conditions/cuts-and-grazes/) - หลักการห้ามเลือด ทำความสะอาด และปิดแผล
- [NHS: Burns and scalds](https://www.nhs.uk/conditions/burns-and-scalds/) - น้ำเย็นไหล 20 นาที และวางฟิล์มคลุมโดยไม่พันรอบอวัยวะ
- [Quaternius](https://quaternius.com/) - ตัวละครฐาน CC0 ตามเครดิตในโปสเตอร์ต้นฉบับ ปรับโมเดลและเพิ่มบาดแผลสำหรับโครงงาน
- Unity VR Template และตัวอย่าง XR Interaction Toolkit 3.5.1 - XR Origin, คอนโทรลเลอร์ และ Simulator
- แนวคิดและตำแหน่งแผลอ้างอิงโปสเตอร์โครงงานของผู้จัดทำ `FirstAid_VR_Poster_A3.pdf`
